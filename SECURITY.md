# سياسة الأمان | Security Policy

## العربية

### الإبلاغ عن ثغرات أمنية

إذا اكتشفت ثغرة أمنية في هذا المشروع، يرجى الإبلاغ عنها بشكل مسؤول عبر البريد الإلكتروني: ziad90216@gmail.com

**يرجى عدم:**
- فتح Issue عام للثغرة الأمنية
- نشر تفاصيل الثغرة في أي مكان عام قبل إصلاحها
- استغلال الثغرة لأي غرض ضار

**ما سنقوم به:**
- الرد على بلاغك خلال 48 ساعة
- التحقيق في المشكلة وإصلاحها في أقرب وقت ممكن
- إشعارك عند الانتهاء من الإصلاح

### النسخ المدعومة

| النسخة | مدعومة |
|-------|--------|
| أحدث إصدار | ✅ نعم |
| الإصدارات السابقة | ❌ لا |

### ممارسات أمنية

- يتم تحديث التبعيات بشكل دوري
- يتم استخدام HTTPS في جميع الاتصالات
- يتم تشفير البيانات الحساسة
- يتم مراجعة الكود بشكل مستمر

## English

### Reporting Security Vulnerabilities

If you discover a security vulnerability in this project, please report it responsibly via email: ziad90216@gmail.com

**Please do not:**
- Open a public Issue for the security vulnerability
- Publish details of the vulnerability anywhere public before it is fixed
- Exploit the vulnerability for any malicious purpose

**What we will do:**
- Acknowledge your report within 48 hours
- Investigate and fix the issue as soon as possible
- Notify you when the fix is complete

### Supported Versions

| Version | Supported |
|-------|----------|
| Latest release | ✅ Yes |
| Previous releases | ❌ No |

### Security Practices

- Dependencies are updated regularly
- HTTPS is used for all communications
- Sensitive data is encrypted
- Code is continuously reviewed
